# Score Prediction

A responsive football-odds predictor that compares normalized 1X2 probabilities with historical matches and estimates:

- Home, draw, and away outcome rates
- Both teams to score (GG)
- Over 1.5 and Over 2.5 goals
- Bookmaker margin and historical disagreement alerts

Open `index.html` directly or publish the repository with GitHub Pages.

> Statistical estimates are not guarantees. Gamble responsibly.
